# Food Construct

Лабораторные работы по курсу «Основы веб-технологий»: сайт компании по доставке бизнес-ланчей.

Каждая папка содержит состояние сайта после соответствующей лабораторной работы:

| Папка | Что сделано |
|-------|-------------|
| `lab1` | Главная страница, стили CSS |
| `lab2` | Страница «Собрать ланч», сетка Grid/Flex, адаптивность |
| `lab3` | Форма заказа с отправкой на httpbin.org |
| `lab4` | Вывод блюд через JavaScript, выбор блюд, стоимость заказа, сортировка |
| `lab5` | Новые категории и блюда, фильтры |

Общие изображения лежат в папке `images`.

## Проверка кода

```
npm install
npm run lint
```
